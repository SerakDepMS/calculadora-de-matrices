## 📖 Descripción del proyecto

**Sumador de Matrices** es una aplicación web básica pero completamente funcional, desarrollada con **HTML, CSS y JavaScript puro**. Permite al usuario:

- Definir el tamaño de las matrices (filas y columnas).
- Añadir o eliminar múltiples matrices dinámicamente.
- Editar cualquier celda con números **negativos**, **decimales** (punto o coma) y **valores grandes**.
- **Calcular la suma total** únicamente al presionar un botón, no de forma automática.
- Visualizar el resultado en una tabla clara y profesional.

Este proyecto es ideal para demostrar conceptos fundamentales de programación web: manipulación del DOM, manejo de eventos, estructuras de datos bidimensionales, diseño responsive y buenas prácticas de código.

---

## 🎯 Características principales

- ✅ **Suma bajo demanda** – Nada se calcula hasta que presiones "SUMAR MATRICES".
- ✅ **Soporte completo de decimales** – Acepta tanto punto (`.`) como coma (`,`) como separador decimal.
- ✅ **Números negativos y grandes** – Sin restricciones de magnitud.
- ✅ **Interfaz dinámica** – Añade o quita matrices sin límite (mínimo 1 matriz).
- ✅ **Redimensionado flexible** – Cambia filas y columnas en cualquier momento (las matrices se reinician a cero).
- ✅ **Diseño profesional y responsive** – Se adapta perfectamente a móviles, tablets y escritorio.
- ✅ **Código limpio y comentado** – Ideal para aprender y modificar.

## 🚀 Cómo ejecutar el proyecto

1. **Clona el repositorio** (o descarga los archivos):
   ```bash
   git clone https://github.com/D3B1A2C4F5E67890/sumador-matrices.git
   ```

2. **Abre el archivo `index.html`** en cualquier navegador moderno (Chrome, Firefox, Edge, Safari).

3. **Comienza a usar la aplicación**:
   - Define filas y columnas.
   - Añade o elimina matrices.
   - Edita los valores.
   - Presiona **"SUMAR MATRICES"** para obtener el resultado.

> No necesitas servidor web ni dependencias externas. Todo corre localmente.

---

## 🧪 Ejemplo de uso

1. **Configuración inicial**: 2 filas, 2 columnas, 2 matrices.
2. **Introduce valores**:
   - Matriz 1: `1.5`, `-2`, `3`, `4,75`
   - Matriz 2: `0.5`, `1`, `-1`, `2,25`
3. **Presiona "SUMAR MATRICES"** → Resultado:
   ```
   [2.0]  [-1.0]
   [2.0]  [7.0]
   ```
4. **Añade una tercera matriz** llena de ceros y vuelve a sumar → el resultado no cambia.
5. **Cambia dimensiones a 3x3** → todas las matrices se reinician a cero.

## 🔧 Personalización y extensión

- **Cambiar colores**: modifica las variables de color en `styles.css`.
- **Añadir más operaciones**: puedes extender `script.js` para incluir resta, multiplicación, etc.
- **Exportar resultados**: implementa una función que copie la matriz suma al portapapeles.
- **Limitar rangos de números**: agrega validación en `parseNumberFromInput`.
